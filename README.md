# Azamat Soliev: Computer Science ePortfolio

Capstone ePortfolio for the Bachelor of Science in Computer Science at
Southern New Hampshire University.

**Live site:** https://azamatsoliev.github.io/

The pages follow the order a reader takes through the portfolio:

| Step | Page | File |
|---|---|---|
| 1 | Professional self-assessment | `index.html` |
| 2 | Code review | `code-review.html` |
| 3 | The artifact: original and enhanced | `artifact.html` |
| 4 | Enhancement One: software design and engineering | `software-design.html` |
| 5 | Enhancement Two: algorithms and data structures | `algorithms.html` |
| 6 | Enhancement Three: databases | `databases.html` |

The application itself lives in its own repository:
[azamatsoliev/azamat-school-admin](https://github.com/azamatsoliev/azamat-school-admin).

Downloads (narratives, self-assessment and code archives) are in
`assets/downloads/`, screenshots in `assets/images/screens/`, and saved test
output in `assets/evidence/`.

The site is plain HTML, CSS and JavaScript with no build step. Every page works
without JavaScript; `assets/js/site.js` only adds the section highlighting, the
screenshot viewer and the menu behaviors. Fonts are IBM Plex Sans, Serif and
Mono, self-hosted under the SIL Open Font License; the license text is in
`assets/fonts/`.
